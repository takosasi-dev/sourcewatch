SourceWatch

調査レポートで引いたページを開くと、ツールバーのアイコンに色が付く。押すと、前に見たときから中身が変わったかを出す。通信はしない。

一覧の読み込み

書き出しスクリプト(sourcewatch_export.py)が作った JSON を選ぶ。

判定に使う指紋

N1 は空白をまとめた文字、N2 はそれに加えて数字の並びを 0 にした文字。主な部分は main → article → [role="main"] → body の最初に見つかった物。

数え

色の付いたページで popup を開いた回数など。この PC の中だけに残し、外へは出さない。

記録

拡張を削除すると記録(基準の指紋と日付)も消える。消す前に「記録を書き出す」で保存しておく。
